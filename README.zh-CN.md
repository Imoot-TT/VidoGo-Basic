## 主要功能

- 在应用内直接浏览视频网站。
- 识别普通视频、HLS 和 DASH 媒体。
- 选择可用的画质和编码格式。
- 复用浏览器登录状态执行下载。
- 录制非 DRM 的 HTML 视频。
- 在本地管理下载、历史记录和收藏夹。

## 从源码运行

```powershell
npm install
python -m pip install -r requirements.txt
npm start
```
