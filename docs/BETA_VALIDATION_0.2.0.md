# VidoGo Basic 0.2.0 封闭验证方案

## 招募对象

- 10–15 位真实内容创作者。
- 每周至少剪辑并发布 3 条内容。
- 日常会保存公开视频或自有/已授权素材，并使用剪映、Premiere Pro、DaVinci Resolve 等剪辑软件。
- 不以“愿意帮忙”为入选条件；必须确实存在素材收集与剪辑工作流。

## 每位测试者的验证任务

1. 首次打开后，不经口头教学，粘贴一条有权使用的公开视频链接。
2. 生成素材包并确认视频、MP3、字幕（来源存在时）、封面和来源信息进入同一项目。
3. 将项目导入自己的剪辑软件素材区。
4. 至少间隔一天再次使用 VidoGo 完成另一条素材。
5. 在 Creator 年付 US$39 与创始买断 US$59 中做真实购买选择；不接受“如果上线我会买”替代付款。

## 漏斗判定

管理后台按匿名用户查看近 30 天步骤：首次打开 → 媒体识别 → 成功保存 → 编辑器导入 → 第二次使用 → 购买完成。统计只在用户主动同意后启用，不采集链接、标题、搜索词、文件名、路径、Cookie 或媒体内容。

## 第一阶段继续投入门槛

- 至少 5 位封测者完成真实付款，退款者不计入。
- 付款必须来自目标用户，不使用开发者、亲友赞助或赠送兑换码凑数。
- 未达到 5 位：暂停扩展站点和高级功能，优先访谈未付费者并修复首次成功路径；不要用下载量或口头好评替代付费验证。
- 达到 5 位：保留价格实验，扩大到下一批 30–50 位创作者，再评估续费与第二次使用率。
