## VidoGo Basic 0.2.0

这是面向真实创作者封闭测试的产品化版本。

- 首页收敛为“粘贴链接 → 生成完整素材包”。
- 同一来源的视频、MP3、字幕与封面合并为一个项目，并只消耗一次 Free 项目额度。
- 套餐精简为 Free 与 Creator；首轮验证价格为 US$39/年或限量 US$59 创始买断。
- 所有 DRM 支持承诺已移除，并明确提示 DRM 保护内容无法处理。
- 新增需用户主动同意的匿名转化漏斗；不采集链接、标题、文件名、路径、Cookie 或内容。

本版本用于 10–15 位高频创作者封测。是否继续投入，以至少 5 位真实付费创始用户为第一道门槛。
