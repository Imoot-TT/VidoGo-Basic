# Basic 主流程降级清单

更新时间：2026-09-22

Basic 的首屏任务只有三件事：粘贴链接、查看下载、管理已保存素材。复杂能力保留在代码中，但不再占用左侧主导航或首屏注意力。

| 能力 | Basic 处理 | 入口 |
| --- | --- | --- |

## 验收标准

- 新启动且没有浏览器标签时，默认进入主页；左侧只显示主页、下载、素材库、设置。
- 主页首屏只有一个 URL 输入和“分析并生成素材包”动作。
- 站点目录默认收起，展开后才展示平台网格和平台管理。
- 账户、套餐、历史、收藏、浏览器仍可通过明确的次级入口访问，不删除已有功能。
- Basic 不允许用户误以为“正在下载”：下载任务在真正收到媒体字节前显示“正在解析/正在连接”，超过阈值显示等待提示。
- 下载任务切换账户前必须处理完未完成任务；已完成的本地文件不受影响。
